# Общие правила форм CRM

Применяются к новым и изменяемым формам во всех разделах. Не создавать отдельную механику для одной услуги, если есть общий компонент.

## Поля

- Страны, гражданство и страна в документе: `src/shared/ui/CountryField.jsx`. Справочник и преобразования — `src/shared/lib/countries.js`. Нельзя заменять справочник текстовым `Input` или локальным коротким массивом стран.
- В интерфейсе показывать название страны и флаг. Для API получать код через `countryCode()`. Старые названия и сокращения читать через тот же справочник. `valueFormat="name"` допускается для существующих форм с текстовыми значениями; преобразование в код выполняется на границе API.
- Несколько стран: `CountryField multiple`, выбор сохраняется по «Применить». Не вводить список стран строкой вручную. Для специальных территорий поставщика требуется его справочник, их нельзя придумывать.
- Короткий фиксированный набор (пол, цель поездки, валюта): общий `Select`. Длинный справочник: поиск и общий боковой выбор. Произвольные комментарии и ФИО допускают текстовый ввод.
- Даты и периоды: `DateField`, `DateRangeField`, `TripDateRangeField` / общий календарь. Нижние действия закреплены, прокручивается содержимое. Минимальная дата зависит от назначения: поездка не в прошлом, дата рождения и документы допускают прошлые даты.
- Телефон: общий `Input` с телефонной механикой / `PhoneInput`, автоматическое определение страны и ограничение длины. Не создавать отдельную маску.
- Люди: выбор из картотеки с сохранением ID, ФИО и нужных данных. Ручной ввод доступен отдельно. Не путать ID участника заказа с ID физлица; исключать повторное добавление.

## Окна и взаимодействие

- Триггер бокового окна обозначать стрелкой вправо, короткого выпадающего списка — вниз. Сохранять доступную подпись, управление с клавиатуры и видимый фокус.
- В боковом окне: общий заголовок, крестик, прокрутка содержимого и нижняя панель действий. Открытый список не должен сжимать или перемещать форму. Никаких глобальных списков черновиков внутри технических окон выбора.
- Клик по подложке и Escape закрывают только верхний слой. Закрытие выбора не сбрасывает поиск и данные предыдущего окна. В редактируемых формах сохранять черновик; в множественном выборе отмена не применяет временные изменения.
- Сразу фокусировать поиск в открытом справочнике; отображать пустой результат. Для серверных данных показывать загрузку, ошибку и повтор, отменять устаревшие запросы.

## Данные и проверка

- Изменение параметров сбрасывает устаревшие расчёты; перед добавлением предложения перепроверяются цена и условия.
- Отсутствующая цена не равна нулю. Недоступные действия не показывать как успешно выполненные. Данные картотеки не перезаписывать уточнениями формы без отдельного сохранения карточки.
- Общий компонент проверять на длинных названиях и узком экране, с вложенным окном и клавиатурой. Изменения справочника проверять также на сохранении в API, восстановлении старых значений и отсутствии дублей локальных справочников.
- Регрессионная проверка стран и гражданства: `test/country-field.test.mjs`.
