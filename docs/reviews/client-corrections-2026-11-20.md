## Проверки

- Полный набор фронтенда: 695 тестов; отдельная проверка четырёх взрослых с разными индивидуальными предложениями и сохранением их в общем оформлении.
- Производственная сборка Next.js проходит.
- Серверные проверки: авторизация, PIN, ограничение попыток, блокировка API, завершение сессии и запрет обновления отозванной сессии; очередь импорта, повтор без дубликата, ошибка распознавания с сохранённым оригиналом; групповые билеты и нормализация TTBooking; личный архив чатов.
- Визуальная проверка тарифов, уведомлений и списка чатов на ширинах 1400, 900 и 390 px; компактного подтверждения также на 320 px.
- Проверка импорта через API сайта: HTTP 202 за 3,21 с; готовый результат за 6,70 с от начала загрузки. Повтор возвращает тот же импорт. Контрольные записи удалены после проверки.

## Границы проверки

- Разные индивидуальные тарифы рассчитаны для взрослых и оформляются отдельными бронями в одном заказе. Детям и младенцам требуется совместный расчёт со взрослым; разбиение общей семейной цены на произвольные суммы не выполняется.
- Скорость ответа и наличие правил определяет также поставщик. Интерфейс показывает фактический результат и ошибки; мгновенную выдачу поставщика гарантировать нельзя.
- Исходный файл GA-TTB0004464.pdf в предоставленных материалах отсутствует: есть только его скриншот. Проверены реальный текстовый PDF, обработка ошибки, сохранение оригинала и работа очереди; точное содержимое указанного файла не воспроизводилось.
- Проверки не создавали реальные авиаброни и не выполняли оплату или выписку билетов.
