# Формы и общие компоненты

При изменении интерфейса форм прочитайте [единый стандарт форм](docs/FORM_STANDARD.md) и используйте общие компоненты из `src/shared/ui`.

Страны и гражданство во всех разделах выбираются через `CountryField`, нормализация выполняется в `src/shared/lib/countries.js`. Не добавляйте отдельные текстовые поля или сокращённые справочники для этих значений. Сохраняйте совместимость с существующими черновиками и форматом API.

При работе с детальными экранами также соблюдайте [стандарт карточек](docs/DETAIL_PAGE_STANDARD.md).
